# NEGARAKU: RHYTHM HEROES

Permainan web interaktif Muzik Tahun 1 Proaktif. Murid menjelajah empat misi rentak dan susunan petikan, mengumpul XP, bintang dan lencana.

## Cara bermain

Buka laman GitHub Pages atau fail `index.html` dalam pelayar moden. Permainan mesra telefon dan tidak memerlukan aplikasi berbayar.

## Tetapan guru

Untuk misi susunan, buka **Tetapan Guru** dan tampal petikan yang dibekalkan guru, satu petikan setiap baris dalam urutan yang betul. Permainan ini tidak menyertakan lirik lagu. Petikan guru dan kemajuan permainan disimpan pada peranti/pelayar murid sahaja.
